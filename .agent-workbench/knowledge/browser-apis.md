## Where 2026 reality differs from "shipped in Chrome 2024–2025, stalled elsewhere"

Completed since late 2025 (previously Chromium-lagging or Chromium-only):
- Anchor positioning: Safari 26 (2025-09-15) + Firefox 147 (2026-01-13) → Baseline 2026.
- Invoker Commands: Firefox 144 + Safari 26.2 (Dec 2025) → all engines.
- Same-document View Transitions + `:active-view-transition`: Firefox 144 (2025-10-14) → all engines.
- Navigation API: Safari 26.2 + Firefox 147 (Jan 2026) → Baseline 2026.
- Trusted Types: Safari 26 (Sep 2025) + Firefox 148 (Feb 2026) → Baseline 2026.
- WebTransport: Safari 26.4 (2026-03-24) was the last engine → Baseline 2026.
- Scroll-driven animations: Safari 26 shipped (Sep 2025) — but Firefox still preview-only, so still not Baseline.
- field-sizing: Firefox 152 (2026-06-16) completed it → Baseline 2026.
- Style queries: Firefox 151 (2026-05-19) completed it → Baseline 2026.
- Customizable select: Safari 27 shipped 2026-09-14; Firefox still flag-only → not Baseline yet.

Still Chromium-only or missing an engine:
- Chromium-only: EditContext (Chrome 121; both others tracking), CSS `if()` (Chrome 137; both others tracking).
- Chromium+Safari (no Firefox): cross-document View Transitions (`@view-transition`).
- Chromium+Firefox (no Safari): moveBefore, Sanitizer/setHTML.
- Firefox flag-only: customizable select.
- Not shipped anywhere stable beyond one engine: Temporal (Firefox stable first, Chrome Jan 2026, Safari preview).

Inversions worth noting: Firefox shipped Temporal (May 2025) and Sanitizer (Feb 2026) BEFORE Chrome; Firefox shipped scrollend (Jan 2023) before Chrome; Edge always equals Chrome in this dataset.

NO SOURCE items: `<command>` element (no MDN page/BCD entry), any View Capture / `Element.getScreenshot()` API (does not exist on MDN), and exact engine versions for `light-dark()`/`color-mix()` (banners only; compat tables render client-side).
