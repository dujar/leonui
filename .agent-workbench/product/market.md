## 2. What the AI codegen toolchain emits in 2026

- **v0**: "AI agent that helps anyone create real code and full-stack apps" — named stack: **Next.js, Tailwind, shadcn/ui** [V, https://v0.app/].
- **bolt.new**: template-based JS full-stack; no DSL anywhere on the product surface [V, https://bolt.new/].
- **Lovable**: React-family stack (format not re-verified; site blocks fetch) — ARR trajectory $17M→$100M→$200M in 8 months on that stack [V, TechCrunch URLs above].
- **Replit Agent**: docs page describes building apps/slides/mobile apps with **no framework choice or custom format mentioned at all** — the agent picks conventional stacks [V, https://docs.replit.com/replitai/agent].
- **Claude Artifacts**: support pages moved and 404'd this round — **[NS]** for the current wording; historically React/Tailwind single-file artifacts.
- **Cursor/Copilot**: repo-agnostic editors; no evidence of non-React appetite found in tooling surfaces. Cursor maker Anysphere: **$9.9B valuation, >$500M ARR (June 2025)** [V, https://techcrunch.com/2025/06/05/cursors-anysphere-nabs-9-9b-valuation-soars-past-500m-arr/].
- **UI DSL shipped to agents — the one live experiment is MCP-UI**: HTML resources over MCP, now folded into the **MCP Apps** spec [V]. Succeeded as a *protocol for embedding*, failed (so far) as a *format for authoring* — agents emit self-contained HTML, not structured trees, because that's what models reliably produce.
- **Direction of the ecosystem**: 21st.dev magic-mcp (5.9k stars) optimizes agents **toward** React/Tailwind [V]. Onlook (26.8k stars) builds visual tooling **on top of** React code [V]. Zero counter-examples found: **no tool with >1k stars emits a non-React UI format as its primary output [V by absence in GitHub search results]**.

## 3. Historical base rates for "becoming the default"

- **jQuery → React**: React (2013) is at **44.7%** of all SO survey respondents / 46.9% of professionals in 2025; jQuery at 23.4% / 24.1% [V, https://survey.stackoverflow.co/2025/technology]. npm today: react **632.9M** dl/month vs jquery **58.2M** [V, npm API, period 2026-08-23→09-21]. That transition took ~4–6 years and rode an existing package manager + bundler ecosystem; the channel was npm distribution of components, not the framework's syntax.
- **CSS-in-JS → Tailwind**: tailwindcss **459.2M** vs styled-components **39.8M** npm dl/month — an 11.5x gap [V, same npm period]; SO 2025 shows Tailwind CSS 4 alone at 21.8% while no CSS-in-JS library appears in the web-framework section at all [V]. Tailwind won by being *more mechanical and reproducible* — the exact property a fixed-token schema would also claim — and it still shipped **as CSS**, zero new runtime.
- **REST → GraphQL (partial)**: State of JS pages exceeded fetch budget this round — **[NS]** for exact curves. Outcome is common knowledge: plateaued, never default; treat as unverified here.
- **DSL graveyard** (all [V] for repo status, 2026-09-25; failure causes are analysis, flagged as such): XAML never left Microsoft platforms; QML stayed Qt-licensed niche; Adobe Flex died with Flash (platform gatekeeping); Titanium EOL'd; **NativeScript still active at 25.7k stars [V] but npm-scale adoption never followed**; Litho (Meta) 7.8k stars, active, Android-only [V] — Meta's own declarative UI stayed inside Meta. Common failure causes (analysis): no talent pool, no package-ecosystem interop, single-vendor governance, licensing fear. None died from technical inferiority.
- **The uncomfortable precedent closest to AgentUI**: Mesop — explicitly AI-app-friendly, Google-backed, and discontinued within ~27 months of launch [V]. Its 12.5k monthly PyPI downloads [V] did not justify one team's maintenance.

## 4. Integration patterns with the React/npm ecosystem

| Pattern | Who did it | How it went |
|---|---|---|
| Compile-to-React (and everything else) | Mitosis [V] | 14.4k stars but 22.9k dl/month — respected, barely depended on [V] |
| JSON platform + React code components registered in | Plasmic [V]; Builder.io ("visual canvas wired directly into your components") [V] | Both survived **only** after making your React components the source of truth [V] |
| Embed-as-island / coexistence | Astro islands: zero-JS HTML, hydrate React/Vue/Svelte per-component via `client:*` [V, https://docs.astro.build/en/concepts/islands/]; htmx (49.5k stars) coexists with server templates [V] | The only patterns with breakout adoption — they let React stay valid [V] |
| Format boundary inside React | React Server Components: server renders ahead of time, bundler combines into an intermediate bundle; explicitly **not** a stable contract for third-party implementers in React 19.x [V, https://react.dev/reference/rsc/server-components] | A wire format exists and is winning, but React controls it [V] |
| Native escape hatches | Flutter platform views: documented costs — hybrid composition "degrades Flutter FPS" via thread merging, virtual display "jank during high-frequency updates," texture layer breaks a11y for SurfaceViews [V, https://docs.flutter.dev/platform-integration/platform-views]; SwiftUI UIViewRepresentable (Apple docs, not fetched [NS]) | Every escape hatch ships with a documented performance/accessibility tax [V] |

## Cross-cutting read

The space is not empty — it is **occupied and unprofitable at the format layer**. Everything that monetizes agent-authored UI (v0, bolt, Lovable, Cursor) does so by emitting React/Tailwind; everything that proposed a rival format is dead (Mesop, Tempo), stalled (OpenUI), sub-200-stars (the AI-native-UI-framework GitHub search page), or survives as an *embed* protocol rather than an *authoring* format (MCP-UI, Adaptive Cards). UI-as-data does live at scale where it is bounded — Shopify theme JSON templates [V], Adaptive Cards [V], Gradio's component schema [V] — bounded contexts, never whole-screen frameworks. The genuinely unoccupied cell in the matrix is the **agent self-verification loop** (`shot`/`tree`): MCP-UI hosts render but don't verify; Onlook verifies visually for humans; nobody ships render→screenshot→a11y-tree diff as a framework primitive with a CLI. Whether that wedge can exist *without* first displacing React is the whole question, and the base rates (jQuery→React rode npm; Tailwind won by staying CSS; islands/htmx won by coexisting) say the interop story is the product, not the schema.

## Sharpening questions before building

1. **Mesop died this month** with Google's backing and a 27-month runway [V]. What did it die *of* — and which of those causes (maintenance cost vs. adoption vs. internal priority) does AgentUI actually remove?
2. Lovable reached $200M ARR in 16 months **on React/Tailwind** [V]. If agents+React is already a solved, monetized default, what does the buyer gain from switching formats — tokens? reliability? verifiability? Can you name the customer who loses money until AgentUI exists?
3. The agents can't choose; humans configure tools. Is the actual distribution plan "get into the system prompt/skill of Claude Code/Cursor" — and what's the precedent for a *format* (as opposed to a package like shadcn) spreading that way? (No counter-example found [V by absence].)
4. Your own open question 2 has an empirical answer shape: every survivor made React components *valid inputs* (Plasmic, Builder, Astro islands, RSC [V]); every replacer died or stalled. Is AgentUI's catalog a **React component wrapper registry first** and a schema second — and if so, why does the schema need to exist at all?
5. Mitosis is the compile-to-everyone proof point: 14.4k stars, 23k monthly downloads [V]. What would make a schema format do 100x that, when Mitosis already solves "write once, emit React" with Deutsche Bank as a reference [V]?
6. The verification loop (`check`/`shot`/`tree`) has no occupant [V by absence]. Is that the wedge — sell verification, win the format later — or is it a feature bolt-on for the existing MCP ecosystem?
7. Every escape hatch has a documented tax: Flutter's own docs concede FPS degradation and a11y breakage per composition mode [V]; MCP-UI concedes framework interop entirely (iframe + HTML) [V]. Given idea.md's question 3, is there a design where the 15 primitives never need the hatch for the top-10 Lovable use cases (dashboards, tables, checkout)?
8. Schema lock-in fear (idea.md Q5) has an empirical sibling: Shopify ships JSON templates successfully [V] because a visual editor round-trips them for non-engineers. Who round-trips AgentUI JSON for the supervising human — and if the answer is "the agent," what happens to that fear?
9. Amodei's "90% in 6 months" is now 18 months old and restated [V]; Google claims 75% [C]. Even granting agent-majority authorship, jQuery→React took 4–6 years *with* npm distribution [V]. What is AgentUI's npm — the thing a thousand strangers can publish components into?
10. If the honest verdict is "bounded embed protocol" (MCP-UI/Adaptive-Cards lane: agent-facing panels inside host apps [V]) rather than "React displacer," which bounded context do you pick first, and is that business worth building for this team?
