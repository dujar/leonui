leonui docs

Forms

ui:model is the two-way bind for form controls: the control writes the signal on input/change, and the signal writes the control whenever it changes otherwise. Selects and text inputs take the string value.

Checkboxes are different

ui:model writes strings, so booleans use ui:bind-checked plus a toggle verb on change — see the settings example in pages/audit-settings.html.

Buttons and forms

  • submit handlers are auto-preventDefaulted — a form with ui:fx="submit: …" will never navigate away.
  • A disabled button fires no events: don't bind disabled and the verb that un-disables it to the same button.
  • focus '#sel', reset '#form' (note: reset re-syncs ui:model paths only — pair it with explicit set verbs for checkbox state) and toast '…' close the loop.
