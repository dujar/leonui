Hello world

The smallest reactive page. State is declared on <body> with ui:state; the <b> binds its text to the name signal; the buttons are events mapped to set verbs.

What just happened

  • At load, the runtime walks the DOM once. ui:state becomes a signal attached to the declaring element.
  • ui:bind="text: name" evaluated name and subscribed to it — that element's text only. No re-render exists in this framework.
  • ui:fx="click: set name = 'leonui'" mapped the click to one verb. The set flipped the signal, which woke exactly the bindings that read it.

Signals resolve by walking up the ancestor chain — the DOM tree is your scope chain. Declare state as high as your page needs it.
