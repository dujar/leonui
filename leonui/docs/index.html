leonui docs

Welcome

leonui is a typed reactive UI runtime where you author plain HTML plus a small attribute grammar — ui:state, ui:bind, ui:each, ui:fx — and a ~33.5 KB runtime makes the page reactive. No build step, no components, no virtual DOM: the browser is the framework.

Every example in these docs is live: the code block is the actual source file, and the panel under it is that file really running. Change the source in your editor and refresh — that's the whole dev loop.

Three files to a running app

index.html
  └─ loads /src/ui.css          (the design system: tokens + components)
  └─ loads /dist/leonui.js (the runtime, auto-boots on import)
  └─ your markup: ui:* attributes declare state, bindings, lists, behavior
serve/serve.ts                    (bun run dev — static pages + mock API)
