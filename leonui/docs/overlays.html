Overlays & toasts

Overlays are mostly the platform, not the framework: popover anchoring/focus is native, invokers open them, and the runtime only styles and wires positions.

The pieces

NeedMarkup
Menu / popover<button popovertarget="m"> + <div popover ui:popover anchor="#menu-btn" placement="bottom-start">
Modal<button command="show-modal" commandfor="d"> + <dialog id="d" ui:modal> (close: command="close")
Toastthe toast 'msg' verb (lands in a role=status host)
Tabsui:tabs container with role=tab/tabpanel markup (arrow keys included)
Accordionplain <details name="group">, styled by the shipped CSS

Because these are platform behaviors, they work before the runtime loads and never break because of it.
