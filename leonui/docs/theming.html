Theming

The shipped stylesheet is a token system: colors, radii, spacing and type live in CSS custom properties, and components reference tokens — never raw values. Brand theming is overriding tokens in one place; dark mode is light-dark(), so it flips with zero JavaScript.

The tokens

FamilyTokens
Color--brand --brand-ink --bg --card --ink --muted --line --danger --warn --success --ring
Shape--r --r-sm --shadow
Spacing--ui-gap-1…8 (2 → 48 px)
Type--ui-text-1…6, --font, --mono

Precedence

Component styles live in @layer ui.base — unlayered app CSS always wins, so a page can override anything without specificity fights. In markdown terms: tokens for values, layers for precedence, variants for choice.
