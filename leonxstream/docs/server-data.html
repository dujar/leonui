Server data

Declare a remote cell with GET: ui:state="tasks: GET /api/tasks". The signal holds {status: 'loading' | 'ok' | 'error', data} — gate panels on it with ui:bind-hidden, and re-run it with the refetch verb.

Writes: call with optimistic updates

ui:fx="click: call PATCH /api/tasks/{task.id} with { done: !task.done }
                optimistic: set task.done = !task.done;
       onfail: toast 'Sync failed — rolled back'"
  • with {…} builds the JSON body; {task.id} interpolates signals into the URL.
  • The body evaluates at event time, before the optimistic set — so !task.done reads the pre-click value.
  • optimistic applies immediately; on failure the runtime rolls back automatically (even if the set removed the row) and onfail runs.

The mock API in serve/app.ts supports ?fail=1 and ?slow=1 to exercise these paths.
