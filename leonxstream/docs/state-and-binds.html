State & binds

Signals are typed cells; bindings are fine-grained: one aspect of one element. The expression language is a whitelist — literals, paths, arithmetic, comparisons, ternaries and a few pure operators — so it can be statically checked and never evald.

Bind aspects

AspectWrites
texttextContent
classclassName (replaces)
hidden / disabled / checked / openthe property, boolean-coerced
attr:nameany attribute

One ui:bind attribute may hold several aspect: expr pairs separated by ;; additional attributes use the hyphen form: ui:bind-class="…" (HTML drops duplicate attribute names).

Computed values

ui:computed="open: …" on a state-bearing element derives a signal that recomputes when its dependencies change — filters, totals, sorted views.

Scoping

Signals resolve by walking ancestors, nearest declaration wins. Declare page-wide state on <body>; a ui:state deeper down shadows it for its subtree.
